# Background music

Drop your MP3 files here and name them:

- `track-1.mp3`
- `track-2.mp3`
- `track-3.mp3`

…or edit the `src` (and titles/artist/artwork) in `lib/content.ts` → `PLAYLIST`.

Until real files are present, the player runs on a virtual clock so the UI
(progress bar, Dynamic Island, lyrics) still animates.
